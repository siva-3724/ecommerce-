# SIVA & HERB OILS
project link https://ecommerceoil.netlify.app/
## 🌿 About the Project
![Uploading Screenshot 2026-09-16 134841.png…]()

**SIVA & HERB OILS** is a modern natural-oil and herbal products website designed to showcase premium oils made with botanical ingredients and traditional inspiration.

The website provides a clean, elegant, and responsive shopping experience for customers to explore products, learn about the brand, and discover natural hair and body care oils.

---

## ✨ Features

* 🌿 Modern natural-product design
* 🛍️ Product showcase section
* 🔎 Product search interface
* 🛒 Buy Now buttons
* ❤️ Favorite/wishlist design
* 📱 Fully responsive layout
* 🎨 Premium herbal-style UI
* 🌱 Natural ingredients presentation
* 📖 Brand story section
* ❓ FAQ section
* 📩 Newsletter section
* 📞 Contact information
* 🦶 Responsive footer
* ⏳ HTML/CSS loading screen

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder in **VS Code**.
3. Make sure the `assets` folder contains all required images.
4. Open `index.html`.
5. Use **Live Server** in VS Code to view the website.
