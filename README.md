
# 🌿 SIVA & HERB OILS

**SIVA & HERB OILS** is a premium natural oil and fragrance e-commerce website designed to showcase traditional, botanical, and herbal oil products through a modern and responsive interface.
![Uploading Screenshot 2026-09-18 113330.png…]()


## ✨ About the Project

SIVA & HERB OILS combines the goodness of natural ingredients with a clean and attractive online shopping experience.

The website is designed to present different types of oils, product details, benefits, and brand information in an easy-to-use layout.

## 🛍️ Features

* 🌿 Natural and herbal oil product showcase
* 🛒 Buy Now / shopping interface
* 🔎 Product search
* 📱 Fully responsive design
* 🎨 Modern and attractive UI
* 🖼️ Product image gallery
* 📖 About / brand story section
* 💚 Natural ingredients information

## 🎨 Website Sections

The home page introduces the SIVA & HERB OILS brand with a hero section, natural oil messaging, featured products, and call-to-action buttons.

Displays different herbal and natural oil products with product images, prices, descriptions, and Buy Now buttons.

### 🌿 Collections

Products are organized into collections to help visitors explore different types of natural oils.

### 📖 Our Story

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project

```bash
cd SIVA-HERB-OILS
```

### 3. Open in VS Code

```bash
code .
```

### 4. Run the website

Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code.
